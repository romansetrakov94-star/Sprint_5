# Sprint_5: UI-тесты для Stellar Burgers

## Описание
Проект содержит автотесты для сервиса Stellar Burgers на Selenium + pytest.

## Установка
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Запустить тесты: `pytest -v`

## Структура
- `conftest.py` – фикстуры
- `locators.py` – локаторы элементов
- `data.py` – генераторы тестовых данных
- `tests/` – тесты по группам функциональности
